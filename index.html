multi-gmail-mcp

A private tool that lets one person work with their own Gmail and Google Drive accounts from a single assistant.

What it does

multi-gmail-mcp is a Model Context Protocol (MCP) server that runs locally on the operator's own computer. It connects several Google accounts that belong to the same operator, so that email and Drive files across those accounts can be searched and managed in one place instead of switching between accounts manually.

Who it is for

It is used internally by a small consulting practice to handle its own correspondence and document files. It is not offered to the public and has no sign-up.

Google data it uses

  • Gmail (read only) — to search and read messages in the operator's own mailboxes.
  • Google Drive — to search, read, create and update the operator's own files.
  • Email address — to label which connected account a result came from.

Where data goes

Nowhere but the operator's own computer. There is no server, no database and no analytics. Access tokens are stored encrypted on that computer. See the Privacy Policy for details.
