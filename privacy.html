Privacy Policy

multi-gmail-mcp — last updated 20 September 2026

1. Who operates this application

multi-gmail-mcp is operated by an individual, contactable at daonbase@gmail.com. It is a private tool, not a commercial service, and it has no users other than the operator and the Google accounts the operator owns or administers.

2. Google user data accessed

With the explicit consent of each connected account, the application requests these OAuth scopes:

  • .../auth/gmail.readonly — read-only access to messages, threads and labels, used to search and display mail.
  • .../auth/drive — access to Drive files, used to search, read, create, rename, update and share files, and to move files to the trash on request.
  • .../auth/userinfo.email — the account's email address, used only to identify which connected account a result belongs to.

3. How the data is used

Data retrieved from Google is used solely to answer the operator's own requests within the session that made them — for example, finding a document across several accounts, reading a message, or creating a file. It is not used for advertising, profiling, or any purpose unrelated to that request.

4. Storage and retention

The application runs entirely on the operator's own computer. It does not operate a server, database or cloud backend, and it does not transmit Google user data to any third party. Message and file contents are held in memory only for the duration of a request and are not written to disk.

OAuth tokens are the only data stored persistently. They are kept in an encrypted file (AES-256-GCM) in the operator's home directory, readable only by that user account, and are deleted when an account is disconnected.

5. Sharing

No Google user data is sold, rented, or shared with any third party. No human other than the operator has access to it.

6. Limited Use disclosure

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

7. Revoking access

Any connected account can revoke access at any time at myaccount.google.com/permissions. Revoking immediately invalidates the stored tokens. Tokens can also be removed locally by disconnecting the account in the application.

8. Children

The application is not directed at children and is not used by anyone under 18.

9. Changes

If this policy changes, the updated version will be posted on this page with a new date.

10. Contact

Questions about this policy: daonbase@gmail.com
